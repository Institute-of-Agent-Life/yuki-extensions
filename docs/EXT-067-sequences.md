# EXT-067 兩個真實插件的 Windows 候選對拍

在空資料目錄啟動已驗簽的 CORE-039，安裝同一 SDK 建置的 Telegram 與 web-fetch。Bot API、模型與 HTTP 代理均限於回環。收件的原 Bot 要等宿主接納才前進 offset。Main 用原 handle 讀頁，再用該次工具回應的內容決定送回的文字。按原 chat 核每個 native ID。冷啟後核 offset、來源操作及送達次數。

第二個案例在平台已接收後斷開，不提供成功回應。查已確認部分、未知部分和後續派發數，重啟時不補發。負例保留真實拒絕。另需核對權限撤回、交換 handle、大原件續讀與逐方法晉級表，依實際執行記錄裁決。
