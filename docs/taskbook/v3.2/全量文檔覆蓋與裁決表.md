### 模型協議：現行官方資料不是固定 adapter 的回執

2026-11-04 查閱。[OpenAI 函式協議](https://developers.openai.com/api/docs/guides/function-calling)區分模型請求工具和應用回填；[DeepSeek Responses 的參數表](https://api-docs.deepseek.com/guides/responses_api/)列支援 tool_choice，卻不支援 previous_response_id，不同型號的搜尋能力也不同。這不改變固定 adapter 當時省略 tool_choice 的事實。[Claude thinking 與工具](https://platform.claude.com/docs/en/build-with-claude/thinking-tool-workflows)需分模型及模式；Yuki 已送 auto 還是未派發，依 H18 的具體程式。[Google 對兩種 API 的簽名管理說明](https://ai.google.dev/gemini-api/docs/thought-signatures)不能拿來把 GenerateContent 的原始 Part 改成 Interactions 的服務端狀態。這些都是文件查證，不是付費探針。
